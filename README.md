# javascript-lotto-precourse

## 기능 목록

## 로또

- [ ] 로또 번호가 6개의 랜덤 숫자로 결정된다.
  - [ ] 개수가 6개가 아니라면 에러를 던진다.
  - [ ] 각 번호의 범위가 1 ~ 45가 아니라면 에러를 던진다.

## 사용자

- [ ] 돈을 가지고 개수에 맞는 로또를 구입한다.
  - [ ] 소지 금액이 1000원으로 나누어지지 않는다면 에러를 던진다.

## 당첨 확인

- [ ] 당첨 로또 번호를 생성한다.
  - [ ] ,로 구분했을때 6개가 아니라면 에러를 던진다.
  - [ ] 구분된 요소가 공백이라면 에러를 던진다.
  - [ ] 구분된 요소가 1 ~ 45 사이의 양수가 아니라면 에러를 던진다.
- [ ] 보너스 로또 번호를 생성한다.

  - [ ] 입력이 공백이라면 에러를 던진다.
  - [ ] 입력이 1 ~ 45 사이의 양수가 아니라면 에러를 던진다.

- [ ] 사용자가 가지고 있는 로또의 당첨 여부를 확인한다.
- [ ] 사용자가 투자한 금액과 대비해 수익률을 계산한다.

## 입력

- [ ] 소지 금액을 입력 받는다.
- [ ] 당첨 번호를 입력 받는다.
- [ ] 보너스 번호를 입력 받는다.

## 출력

- [ ] 구매 내역을 출력한다.
  - [ ] 구매 로또 번호를 오름차순으로 출력한다.
- [ ] 수익률을 출력한다.
