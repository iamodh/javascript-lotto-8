# javascript-lotto-precourse

## 기능 목록

## 로또 (Lotto)

- [x] 번호들을 전달받아 로또를 생성한다.
  - [x] 로또 번호의 개수가 6개가 아니라면 예외가 발생한다.
  - [x] 로또 번호에 중복된 숫자가 있으면 예외가 발생한다.

## 사용자 (User)

- [x] 투자 금액을 전달받아 사용자를 생성한다.
- [x] 투자 금액으로 로또를 구입한다.
  - [x] 투자 금액이 로또의 가격으로 나누어 떨어지지 않으면 예외가 발생한다.

## 당첨 로또 (WinningLotto)

- [x] 당첨 로또 번호를 저장한다.
  - [x] 당점 로또 번호의 개수가 6개가 아니라면 예외가 발생한다.
  - [x] 당첨 로또 번호에 중복된 숫자가 있으면 예외가 발생한다.
- [x] 보너스 로또 번호를 저장한다.
  - [x] 보너스 로또 번호가 당첨 로또 번호와 중복되면 예외가 발생한다.

## 당첨 확인 (Checker)

- [ ] 당첨 로또 번호를 생성한다.
- [x] 당첨 로또 번호가 주어진 범위 사이의 양수가 아니면 예외가 발생한다.
- [ ] 사용자가 가지고 있는 로또의 당첨 결과를 확인한다.
- [ ] 사용자가 투자한 금액과 대비해 수익률을 계산한다.

## 입력 (Input)

- [ ] 소지 금액을 입력 받아 숫자로 변환 후 반환한다.
  - [ ] 입력된 소지 금액이 양의 정수가 아니라면 예외가 발생한다.
- [ ] 당첨 로또의 번호들을 입력 받아 숫자 배열로 변환 후 반환한다.
  - [ ] 입력된 당첨 로또 번호 중 양의 정수가 아닌 번호가 있다면 예외가 발생한다.
  - [ ] 입력된 당첨 로또 번호 중 로또 번호의 범위에 포함되지 않는 번호가 있다면 예외가 발생한다.
- [ ] 당첨 로또의 보너스 번호를 입력 받아 변환 후 반환한다.
  - [ ] 당첨 로또의 보너스 번호가 양의 정수가 아니라면 예외가 발생한다.
  - [ ] 당첨 로또의 보너스 번호가 로또 번호의 범위에 포함되지 않는다면 예외가 발생한다.

## 출력

- [ ] 구매 내역을 출력한다.
  - [ ] 구매 로또 번호를 오름차순으로 출력한다.
- [ ] 수익률을 출력한다.
